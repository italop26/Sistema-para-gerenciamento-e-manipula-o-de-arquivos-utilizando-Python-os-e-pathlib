Projeto desenvolvido em Python para praticar manipulação de arquivos e diretórios utilizando `pathlib` e `os`.

## Funcionalidades

- Listar arquivos e pastas
- Criar arquivos
- Atualizar arquivos
- Excluir arquivos
- Criar pastas
- Excluir pastas
- Renomear arquivos e pastas

## Tecnologias

- Python
- pathlib
- os
